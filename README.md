# AI Chatbot

A Java Swing-based AI Chatbot developed as part of the CodeAlpha Java Programming Internship.

## Features

* Interactive chatbot interface
* User-friendly GUI built with Java Swing
* Keyword-based Natural Language Processing (NLP)
* Intelligent predefined responses
* Real-time chat interaction
* Object-Oriented Programming (OOP) implementation

## Technologies Used

* Java
* Java Swing
* OOP Concepts

## Sample Questions

* Hello
* What is Java?
* What is OOP?
* How are you?
* Tell me about UPSC
* Bye
